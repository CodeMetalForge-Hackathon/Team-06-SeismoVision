# Forge 2026 logistics

Source: the team's [Saturday mission brief](archive/forge-2026-saturday-mission-brief.pdf). Check organizer announcements for changes and final submission instructions, scheduled for Sunday at 11:00 a.m. Eastern.

## Mission fit

**Operation Lost and Found** asks teams to solve one focused piece of search and rescue in dangerous environments. This project primarily addresses **Objective 02: Detect Life and Hazards**, specifically structural risk to responders. The brief favors a working focused capability over a broad unfinished system.

## Judging

Four criteria have equal weight, each scored 1–5 for a 20-point maximum:

1. Real-world relevance: a clear user, problem, and operating environment.
2. Working live demo: real functionality built during the event; partial progress on a hard problem can score.
3. Deployability: credible hardware, power, latency, bandwidth, and reliability path.
4. Ideation: a fresh approach, combination, or use of available hardware.

At the table, be ready to show it working, separate prior work from weekend work, explain what did and did not work, and explain the path beyond a laptop. The brief explicitly says code cleanliness, pitch polish, production readiness, and a finished product are not scored items.

## Schedule and submission

- Saturday, November 7, 10:00 a.m. Eastern: build window starts.
- Sunday, November 8, 11:00 a.m. Eastern: final submission instructions from organizers.
- **Sunday, November 8, 12:00 p.m. Eastern: hard submission cutoff. Push all code to the team repo before then.**
- Sunday, 12:00–2:00 p.m.: table judging, about 15 minutes with one judge; keep one teammate at the table.
- Sunday, 2:45 p.m.: five finalists present on the main stage for 10 minutes each.

The brief allows prior ideas, existing projects, open source, and AI coding tools, but judges score only work built between the Saturday start and Sunday cutoff. Keep a clear commit history and explain prior work. A live table demo is recommended; a recorded backup is optional and must be identified as recorded.
